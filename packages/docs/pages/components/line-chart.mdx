## Examples

### Smooth curves

`curve` sets how the lines connect their points: `linear` (the default) draws straight segments, `smooth` draws a spline. Straight segments read exact values more precisely; smooth curves suit trend-forward narratives. A smooth curve never goes beyond the values it joins, but between categories it draws values nobody measured — treat it as a trend, not as exact readings.

<Preview name="line-chart-smooth" />

### Multi-series

Pass more than one series and the legend appears automatically, one entry per series.

<Preview name="line-chart-multi-series" />

### Series aggregation

Only `maxSeries` series render (default `3`); the rest fold into a single `Others` aggregate that takes the last slot's color. Raise `maxSeries` to give more series their own name and color. It is capped at `6` — the palette length — and series past the cap still aggregate, so raising `maxSeries` never drops data.

<Preview name="line-chart-max-series" />

### Missing data

A `null` value renders a gap at that category: the line is not interpolated across the missing point, so absent data never masquerades as a real value.

<Preview name="line-chart-missing-data" />

### Marker density

The chart decides whether to draw a marker at every point. When points crowd the width — 90 daily values on a narrow panel, say — the markers are hidden across every line so the trend reads as a line, not a bead necklace. Widen the chart enough, or chart fewer points, and every point gets a marker. The rule is all-or-nothing for the whole chart: a dense series never draws only some of its markers.

A line's hovered point always shows a marker even when they're hidden; a value whose neighbours are both gaps (an isolated reading between nulls) keeps its marker too, because without a connecting line segment the point would otherwise disappear.

### Tooltip with deltas

Each series can carry a `deltas` array — one entry per category — shown in the hover tooltip beside the value. `direction` (`up` / `down` / `flat`) and `tone` (`success` / `critical` / `neutral`) are independent, because a decrease is not inherently bad: falling complaints is `direction: 'down'` with `tone: 'success'`. The comparison data need not be plotted — it only feeds the tooltip.

<Preview name="line-chart-deltas" />

### Loading state

Pass `loading` to show a skeleton placeholder instead of the chart while data is being fetched.

<Preview name="line-chart-loading" />

### Empty state

When no series has any non-null value, the chart renders its empty state. Override the message through the `messages` prop, or let it localize from the surrounding `LocaleProvider`.

<Preview name="line-chart-empty" />

### Negative values

Negative values render below the zero line. When a value falls below zero, the chart emphasizes that line — the grid's 1px weight, in a darker gray — so the split between positive and negative stays legible; the bottom line remains an ordinary gridline.

<Preview name="line-chart-negative" />

### Localization

Internal messages — the empty state and the `Others` aggregate — localize from the surrounding `LocaleProvider`. Data supplied through props is not translated: series names and categories are the consumer's to localize.

<Preview name="line-chart-localized" />
