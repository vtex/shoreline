# AIMessagesI18nProvider

<ComponentDescription>Gives message pieces their localized labels. AIMessages mounts it for you; mount it yourself to render message pieces outside AIMessages, for example in a test or a story. It renders no element.</ComponentDescription>

```tsx
<AIMessagesI18nProvider messages={{ reasoningDone: 'Done thinking' }}>
  <AIReasoningRoot status="complete">
    <AIReasoningHeader />
  </AIReasoningRoot>
</AIMessagesI18nProvider>
```

The labels come from the built-in catalog of the `LocaleProvider` locale (`en-US` or `pt-BR`). `messages` replaces some of them; unset keys keep the default. The keys and their texts are listed in [Labels and languages](/components/ai-messages#labels-and-languages). A message piece outside both `AIMessages` and this provider throws.
