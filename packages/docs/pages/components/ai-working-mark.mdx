## Usage

It needs no provider and no message around it, so you can use it anywhere:

```tsx
import { AIWorkingMark } from '@vtex/shoreline-ai'

<AIWorkingMark />
```

It is a 14px glyph in a 16px box. Import the package styles once, as on [AIMessages](/components/ai-messages#setup).

## Change the glyph

There are three ways to replace the My Assistant mark, from the narrowest to the widest:

1. **Children of `AIWorkingMark`**, for one mark you render yourself:

   ```tsx
   <AIWorkingMark>
     <IconSparkle />
   </AIWorkingMark>
   ```

2. **Children of [AIReasoningMark](/components/ai-reasoning/ai-reasoning-mark)**, for the mark of a reasoning template:

   ```tsx
   <AIReasoningHeader>
     <AIReasoningMark>
       <IconSparkle />
     </AIReasoningMark>
     <AIReasoningLabel />
   </AIReasoningHeader>
   ```

3. **`workingMark` on [AIMessages](/components/ai-messages)**, for every reasoning mark in the list, including the header shown before the first part:

   ```tsx
   <AIMessages workingMark={<IconSparkle />} />
   ```

A reasoning mark uses its children first, then `workingMark`, then the My Assistant mark.

## Reduced motion

With `prefers-reduced-motion: reduce` the mark does not rotate and has no enter animation: it pulses slowly instead.

## Optional props

<PropsDocs name="ai-working-mark" />

`AIWorkingMark` also accepts the props of a `span`.

## Accessibility

The mark is decorative and hidden from assistive technology (`aria-hidden`). Put the state in text next to it, for example with [AIThinkingIndicator](/components/ai-thinking-indicator).

## Styling

| Attribute | Region |
|-----------|--------|
| `[data-sl-ai-working-mark]` | The 16px box. It scales in when it appears |
| `[data-sl-ai-working-mark-glyph]` | The 14px glyph, which turns half a turn every 1.2 seconds |
