<Preview name="ai-thinking-indicator" />

## Usage

It needs no provider and no message around it, so you can use it anywhere:

```tsx
import { AIThinkingIndicator } from '@vtex/shoreline-ai'

<AIThinkingIndicator>Searching orders…</AIThinkingIndicator>
```

It is a `span` with no default text, no dots and no `role`. Pass the text as children. When the text must be announced, make it a live region yourself, for example with `role="status"` or by placing it in an `output` element. Import the package styles once, as on [AIMessages](/components/ai-messages#setup).

## Reduced motion

With `prefers-reduced-motion: reduce` there is no sweep: the text stays plain, in `--sl-fg-base-soft`.

## Optional props

<PropsDocs name="ai-thinking-indicator" />

`AIThinkingIndicator` also accepts the props of a `span`.

## Styling

| Attribute | Region |
|-----------|--------|
| `[data-sl-ai-thinking-indicator]` | The text. A band in `--sl-color-gray-4` sweeps over `--sl-fg-base-soft` text every 2.4 seconds |
